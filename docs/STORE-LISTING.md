# Chrome Web Store 上架内容草稿

## 基本信息

- 名称：栖签 — 标签归档
- 类别建议：生产力工具
- 主要语言：简体中文
- 单一用途：把用户主动选择的浏览器标签保存到专用 Chrome 书签文件夹，并提供整理与恢复界面。
- 简短说明：把标签存进书签，分组整理、随时恢复，并通过 Chrome 书签同步到其他电脑。

## 详细说明

栖签帮你收起暂时不用的标签，并把网址与标题保存为普通 Chrome 书签。下次可以在资料库中搜索、分组、标星、记笔记、设任务或恢复标签。支持当前窗口、选中标签、左右侧、其他标签及所有窗口归档；默认保留固定标签，并在确认书签写入后才关闭源标签。

归档位于专用书签文件夹（历史兼容名称为 BetterTab）。只要在各设备的 Chrome 开启同一账号的书签同步，就可以由 Chrome 同步这些书签和组元信息。同步速度与冲突处理取决于 Chrome。栖签不提供独立云账号或开发者服务器。

支持 OneTab 文本导入与导出、JSON 完整备份，以及离线 HTML 分享文件。还可使用回收站、锁定、快捷列表、右键菜单和键盘快捷键。界面采用 shadcn/ui 风格，支持浅色、深色及系统主题。

不包含公开分享链接、二维码或服务端分享撤销。相同网址在同一组中的星标和任务状态可能共享。

## 权限说明（隐私表单）

| 权限 | 用途 |
| --- | --- |
| tabs | 读取用户要求归档的标签标题、网址和位置；在保存后关闭源标签，恢复时重新打开 |
| bookmarks | 在专用目录中保存、整理、读取及删除归档书签和组元信息 |
| storage | 本地保存设置、错误提示和扩展自检报告 |
| contextMenus | 提供归档当前、选中、左右侧及其他标签的右键菜单 |
| tabGroups | 保存及恢复 Chrome 原生标签组的名称和颜色 |

数据类型披露建议：网站浏览活动（网址、标题）；用户提供的内容（组名、笔记、任务等）。这些数据仅用于用户请求的标签归档与整理，保存于 Chrome 书签或本地扩展存储。Chrome 书签同步由 Chrome/Google 处理。请在开发者后台按实际字段逐项核对，勿笼统声明“完全不处理用户数据”。
