# 栖签隐私政策

更新日期：2026-09-27

栖签的用途是将用户主动选择的 Chrome 标签归档为书签，并在界面中整理和恢复。扩展会读取归档范围内标签的网址、标题、固定状态和原生标签组信息。归档时，它将网址和标题写入 Chrome 的专用书签文件夹（历史兼容名称为 BetterTab）；组名、笔记、分类、星标、任务和回收站状态以元信息书签形式保存在该文件夹。设置、错误提示和自检报告保存在 Chrome 扩展的本地存储中。

如果用户在 Chrome 中开启书签同步，Chrome 和用户的 Google 账号可能将专用书签文件夹同步到其他设备。同步由 Chrome 提供，栖签不运行自己的同步服务器，也不向开发者服务器发送标签、书签或笔记。用户主动选择导出时，扩展会在本机生成文件；它不会自动上传。点击归档链接或恢复标签会由 Chrome 正常访问目标网站。运行自检时，扩展会创建带唯一标记的临时书签和示例网页标签，并在结束时尝试清理。

开发者不接收、出售或用于广告投放这些数据。扩展不读取网页正文、密码、Cookie 或浏览历史数据库。归档的具体网址可能包含用户自行访问的网站所附带的信息，因此由用户决定要归档哪些标签。

用户可在栖签中恢复、删除或导出归档，也可在 Chrome 书签管理器直接编辑或删除专用文件夹。卸载扩展不会自动删除已创建的 Chrome 书签；需要用户在书签管理器中删除。Chrome 书签同步的数据保留和删除依用户的 Chrome 与 Google 账号设置而定。

本扩展对从 Chrome API 获得的信息的使用遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求。若隐私处理方式变更，本政策和商店披露信息会相应更新。
