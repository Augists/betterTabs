# 商店截图清单

Chrome Web Store 至少需要一张真实扩展界面截图，尺寸 1280×800 或 640×400，PNG/JPEG，完整矩形画面。请在已加载的 0.2.0 栖签管理页，用非私人测试网址建立两组归档后截取主界面。保留左侧导航、搜索框、分组、单条标签操作和顶部工具栏。避免显示私人书签、地址栏令牌、个人账户资料。

截图需展示实际运行的扩展；`release/small-promo-440x280.png` 是宣传图，不能代替界面截图。若截取 1280×800，直接保存为 `release/store-screenshot-1280x800.png`，便于上架时选择。可再附一张设置或快捷列表截图，但不是必需。
